ABSTRACT
--------------------------------------------------------------------------------
Word segmentation is a core preprocessing task in Natural Language Processing,
especially for scripts that do not explicitly mark word boundaries (such as
Chinese, Japanese, Thai) or for domain-specific English tasks (like tokenizing
concatenated URL segments or social media hashtags). This report explores two
key techniques for word segmentation: a Greedy longest-match heuristic and a
Dynamic Programming (DP) approach utilizing unigram log-probabilities derived
from word frequencies. The two models are evaluated on a test dataset of 1,000
test cases from the Brown Corpus. The results show that the Dynamic Programming
approach attains an accuracy of 98.20% and an average Levenshtein Edit Distance
of 0.0280, significantly outperforming the Greedy baseline (69.10% accuracy,
1.2900 average edit distance).

1. INTRODUCTION & PROBLEM STATEMENT
--------------------------------------------------------------------------------
The goal of word segmentation is to reconstruct the original sequence of words
from a concatenated string of characters without spaces (e.g., converting
"thecitytakes" into "the city takes").

2. ALGORITHMS IMPLEMENTATION
--------------------------------------------------------------------------------

2.1 Greedy (Longest-Match) Segmentation
The Greedy algorithm attempts to segment the string starting at index i = 0 by
matching the longest prefix in the vocabulary:
1. Try prefixes of the substring text[i:j] from the longest possible length
   down to 1.
2. If a matching word is found in the vocabulary set:
   - Append the word to the output list.
   - Advance i to j.
3. If no matching word is found:
   - Fall back to consuming a single character text[i] as an individual token
     to ensure the algorithm makes progress.
   - Advance i by 1.

Time Complexity: O(N^2) where N is the length of the input string.
Drawback: It makes locally optimal choices without lookahead or backtracking,
which leads to error cascades.

2.2 Dynamic Programming (DP) Segmentation
The Dynamic Programming approach computes the globally most probable segmentation.
Under a unigram language model, we assume the probability of a word sequence is the
product of individual word probabilities:
P(W) = P(w_1) * P(w_2) * ... * P(w_k)
log P(W) = log P(w_1) + log P(w_2) + ... + log P(w_k)

Using log-probabilities avoids floating-point underflow when multiplying many
small fractions.

Mathematical Formulations:
- Unigram Probability:
  P(word) = frequency(word) / Total Corpus Words
- Log Probability:
  log10(P(word)) = log10(frequency(word)) - log10(735,040)
- Out-of-Vocabulary (OOV) Smoothing:
  If a substring is not in the vocabulary, we assign a penalty proportional
  to the length of the string:
  log10(P(OOV)) = -12.0 * len(word)

DP Recurrence:
Let dp[i] be the maximum log-probability of segmenting the suffix text[i:].
- Base Case:
  dp[N] = 0.0
- Recurrence:
  dp[i] = max_{i < j <= N} ( log10 P(text[i:j]) + dp[j] )
- Reconstruction: We track optimal split points using a parent list where
  parent[i] stores the index j that yielded the maximum score for dp[i].
  We reconstruct the segmented text by traversing the parent links from index 0.

3. EVALUATION METRICS
--------------------------------------------------------------------------------
We evaluate both algorithms using two core metrics:
1. Accuracy: The percentage of test cases where the predicted segmentation
   matches the ground truth exactly.
   Accuracy = (Correct Predictions / Total Test Cases) * 100
2. Edit Distance: The Levenshtein distance at the character level (including
   spaces), which measures the minimum number of insertions, deletions, or
   substitutions required to transform the prediction into the ground truth.

5. DISCUSSION & SAMPLE PREDICTIONS
--------------------------------------------------------------------------------
Below is a comparison of predictions on representative test cases:

Example 1:
- Input String: "itthatthecitytakestepstothisproblem"
- Ground Truth: "it that the city take steps to this problem"
- Greedy Pred:  "it that the city takes t eps to this problem" (Incorrect)
- DP Pred:      "it that the city take steps to this problem" (Correct)

Example 2:
- Input String: "oftitlelawwasalsobythe"
- Ground Truth: "of title law was also by the"
- Greedy Pred:  "of title law was also by the" (Correct)
- DP Pred:      "of title law was also by the" (Correct)

Example 3:
- Input String: "failuretodothiswillcontinuetoplaceaon"
- Ground Truth: "failure to do this will continue to place a on"
- Greedy Pred:  "failure to do this will continue to place a on" (Correct)
- DP Pred:      "failure to do this will continue to place a on" (Correct)

Error Analysis of Greedy:
In Example 1, the Greedy algorithm encounters "takestepstothis...". It matches
"takes" because it is a valid vocabulary word and is longer than "take".
However, this local decision leaves the remaining characters "tepsto..." which
cannot be segmented correctly, resulting in "takes t eps".

The Dynamic Programming algorithm evaluates both segmentations globally:
log10 P("take") + log10 P("steps")
  = -3.08 + -3.79 = -6.87

log10 P("takes") + log10 P("t") + log10 P("eps")
  = -3.93 + -3.98 + -36.00 = -43.91

Since -6.87 > -43.91, the DP algorithm correctly identifies "take steps" as the
optimal segmentation.

--------------------------------------------------------------------------------
6. CONCLUSIONS & KEY FINDINGS
--------------------------------------------------------------------------------
1. Local vs. Global Context: The Greedy algorithm fails on boundary ambiguities
   because it makes local decisions. Dynamic Programming solves this by
   optimizing the segmentation globally.
2. Log-Probabilities Prevent Underflow: Working with log-probabilities instead
   of raw probabilities prevents mathematical errors caused by floating-point
   underflow.
3. Robustness via Smoothing: A length-based penalty for OOV words allows the DP
   algorithm to be robust even when encountering characters or symbols outside
   the main dictionary.
